# Mangalam HDPE Pipes Website

A responsive industrial product showcase website built from Figma design using HTML, CSS, and JavaScript.

##  Features

- Fully responsive design
- Desktop, tablet, and mobile layouts
- Product hero section
- Image gallery with thumbnails
- Manufacturing process section
- Technical specifications table
- Portfolio showcase
- Testimonial slider with pagination
- Modern UI inspired by Figma design

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Font Awesome

## Responsive Breakpoints

- Desktop
- Tablet
- Mobile
